# 方法と検証

[English](METHOD.en.md)

## 手順
1. **画像**：Gallica の BnF Français 3013（ark:/12148/btv1b9060138r、マイクロフィルムから作った画像）。インクの葉番号で葉を確かめた。f. 102r＝164コマ、f. 102v＝165コマ、宛名＝167コマ（no. 42 は f. 99r＝159コマ、f. 99v＝160コマ、宛名＝162コマ）。BnF の目録の「Fol. 102」「Fol. 105」は、インクの葉番号より3つ大きい。画像はこのリポジトリに含めていない。
2. **鍵**：ミラノ国立文書館 Carteggio Sforzesco cart. 1591 no. 24 の鍵の紙（DECODE R5258、裏書「Cum equite Bilie / extracta ex cifris」＝騎士 Bilia との暗号から抜き出したもの）。値は、Cyphersolver 台帳（targets/gilino1527）の鍵の紙の書き起こしと、George Lasry 氏が同じ鍵を書簡から独立に復元したもの（同じ台帳に寄稿）から取った（data/key.tsv、出どころは source 列）。台帳では、この鍵で「el Gilino」のミラノ公宛て書簡（BL Cotton Vespasian C IV ff. 214–218、1527-09-15）を読んでいる。
   - 方式：棒の付いた基の字（G・B・o〔D〕）に2桁の数を付け、数の順に音節を並べた表（B.31 ba … B.50 gu、B.51 fa … B.55 fu、D.51 la … D.65 nu、G.56 pa … G.80 tu、o.33 va … o.47 zu）、裸の数字などの字母、数語の符号（H.27 che、H.28 come など）、名前の符号、無効字。
   - 鍵の紙の書き起こしに同じ形がない5種の記号（ß・£・F・tt・qx）は、この書簡の文脈で値を決めた（f. 102r で41記号、8.1%）。対照は、これらを外した条件でも回した。
3. **書き起こし**：Claude Opus 5.5 が原寸の画像から、記号名で行ごとに書き起こした（data/transcription_f102r.txt）。名前は基の字と数（G.67、B.42、o.53、H.27 など）と、裸の記号（19、25、÷、x、ß など）。
4. **解読**：src/decode.py で鍵を当てた（data/decoded_f102r.txt）。読み（[READING.md](READING.md)）は、それに語の区切りと句読点を補ったもの。

## 照合と、画像による確かめ
- **照合**：OpenAI の Codex（codex-cli 0.163.0-alpha.10.2、既定のモデル。実行記録にモデル名は出ない）に、1行1枚の行画像37枚と、記号名の一覧（second/PROMPT.md。形の説明だけで、値・1回目の書き起こし・鍵・読みは入れない）だけを渡し、空のフォルダから読み取りだけの設定で3回別々に走らせた（`codex exec --ephemeral -s read-only`）。実行記録には、どの回も返答1件だけがあり、コマンドの実行やファイルの読み込みはない。
- **画像による確かめ（1回目）**：3回中2回以上が1回目と違う同じ値を読んだ51か所を、Codex と Claude Sonnet に、行画像で別々に判定させた（check/round1/。候補2つの順番はばらばらにし、値や読みは渡さない）。両方が Codex の読みを選んだ15か所を直し、両方が1回目を選んだ14か所は直さず、割れた22か所は1回目のままにした。
- **画像による確かめ（2回目）**：割れた22か所を、原寸から切った3分割の拡大画像で、もう一度別々に判定させた（check/round2/）。両方が Codex の読みを選んだ5か所を直し（2か所は記号を消した）、両方が1回目を選んだ5か所は直さず、12か所は割れたまま（うち f. 102r が8か所、[OPEN.md](OPEN.md)）。
- f. 102r だけでは、1回目の31か所のうち9か所、2回目の14か所のうち3か所を直した（計12か所）。
- 直すのは、2つのモデルの判定がそろった所だけにした。多数決や、文脈に合うかどうかでは直していない。

## 数字（f. 102r、505記号）
| 項目 | 結果 |
|---|---|
| **独立の2回目**：直した後に、新しく走らせた Codex 3回（second/codex_pass1–3.txt）と、直した書き起こしの値の一致率 | 94.9・94.9・94.9%（名前どおり 89.3・90.1・90.3%）。この比較では書き起こしを直していない |
| 照合の記録（判定には使わない）：直す前の書き起こしと、最初の Codex 3回（second/earlier_v1/）の値の一致率（2ページ合わせて） | 89.3〜91.2%（名前どおり 85.0〜86.7%） |
| 照合の記録：1回目の確かめの後の書き起こしと、2回目の Codex 3回（second/earlier_v2/）の値の一致率（f. 102r） | 94.5・94.1・95.3%（名前どおり 89.7・89.1・90.5%） |
| 鍵の値をかき混ぜた対照（1,000回）：全記号 | 本物 −2.218、かき混ぜた鍵の最大 −2.844、本物以上 0回 |
| 同：鍵の紙の値だけ（文脈で決めた5種を外す） | 本物 −2.179、最大 −2.687、本物以上 0回 |
| 同：Codex の独立の2回目の3つの書き起こしに、鍵をそのまま当てる | 本物 −2.256・−2.222・−2.228、最大 −2.765・−2.710・−2.648、どれも 0回 |
| 値の付いた割合 | 504/505（99.8%）。推定（[ca]）を入れて 505/505。鍵の紙の値だけなら 463/505（91.7%） |
| 較正 | なし（下） |

- 一致率は、行ごとに記号の並びを編集距離で対応させ、1回目の記号のうち一致したものの割合（src/xcompare.py、src/perpage.py）。「値の一致」は、鍵で同じ値になる別名（25 と as など）を同じとみなしたもの。
- 対照：鍵の値を、書簡に出る記号のあいだでかき混ぜ、イタリア語らしさを本物の鍵と比べた（src/control.py）。イタリア語らしさは、文字3連の対数尤度の平均。`wordfreq` の伊語上位5万語を頻度で重み付けし、暗号文に語の区切りがないので、上位2,000語の語の境目をまたぐ3連も入れた。名前と語の符号は採点から外した。

## 較正がない理由
この書簡にも、同じ巻のほかの書簡にも、この鍵で書いた暗号の当時の解読や刊本が見つからない（BnF の目録に「déchiffrement」の記載はなく、f. 102v の平文は結びと追伸で、暗号の解読ではない）。そのため、答えを見ずに読んで正しさを測る較正はできなかった。

## AI の使用
- Anthropic の Claude（Claude Code、Claude Opus 5.5）：書き起こし、鍵の表の組み立て、解読、読み、スクリプト、文書。
- OpenAI の Codex：独立の書き起こし（計9回）と、画像による確かめの判定。
- Claude Sonnet：画像による確かめの判定、先行の確かめ（[PRIOR_CHECK.md](PRIOR_CHECK.md)。書き起こしと読みを作っていない読み手）。
- 人：対象の選定と、公開の判断。**人は書き起こしを確かめていない。**

## 限界
- 記号名の一覧と行画像の切り出しは、1回目の書き起こしをした側が作った。名前の選び方は、その見方に引きずられている。
- 2つの AI が同じ読み誤りをしている所は、照合では見つからない。
- 鍵の値は、鍵の紙の書き起こし（Cyphersolver 台帳）に拠り、鍵の紙の画像はこちらでは見ていない。
